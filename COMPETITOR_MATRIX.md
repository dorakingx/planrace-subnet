# Competitor matrix

| Category | Representative networks/products | Commodity | PlanRace difference |
|---|---|---|---|
| LLM inference | Chutes, Targon, OpenRouter | generated tokens | executable query artifacts with exact replay |
| Search/research | Desearch, QueryAgent, Perplexity | answers and citations | known-query optimization, not answer generation |
| Code intelligence | Subnet 1, code agents, SWE benchmarks | code patches/completions | narrow SQL artifact and cheap deterministic oracle |
| Compute markets | ComputeHorde, Akash, io.net | compute capacity | rewards optimization quality, not leased hardware |
| Data markets | Masa, Vana-style networks | datasets/signals | produces transformations, not raw data ownership |
| Database optimizers | native PostgreSQL/cloud advisors | centralized recommendations | open solver competition plus validator replay |

The closest observed hackathon overlap was QUASAR's code/kernel optimization,
which caused KernelForge to be dropped. QueryAgent concerns database Q&A rather
than exact-result query-plan competition. Source-level landscape follows.
