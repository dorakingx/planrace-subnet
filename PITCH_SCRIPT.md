# Pitch script

Every database team has correct queries that become expensive as data and
releases change. Today optimization expertise is centralized and opaque.
PlanRace creates a continuous market for executable query improvements.

Miners may use any solver to return SQL and bounded index artifacts. Validators
commit task material, authenticate every request, reproduce the known answer on
unrevealed test rows, and award zero to any observed result mismatch. Only then do they
measure warm latency, setup cost, and plan complexity and convert scores to
Bittensor weights. Verification is cheaper than discovery, which is the economic
asymmetry a subnet needs.

The historical protocol v1 localnet run caught a deliberately faster-looking
wrong miner and finalized 100% local-chain weight to the exact miner. Its signed
evidence manifest also discloses v1 seed leakage and unsigned responses rather
than presenting them as solved. The next milestones are the hardened flow
on testnet, disposable sandbox workers, and DuckDB/PostgreSQL tracks for database
teams and platforms. PlanRace turns query optimization from a vendor feature
into an open, measurable digital commodity.
