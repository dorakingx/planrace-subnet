# Pitch script

Editable checkpoint deck: `submission/PlanRace_Checkpoint_Pitch.pptx`.
Interim narrated version source: `submission/pitch-narration.json`.
It intentionally presents the verified localnet result and labels testnet as the
next gate. Replace the testnet-pending material only after the signed testnet
manifest and finalized metagraph readback exist.

Every database team has queries that remain logically correct but become
expensive when schemas, data distributions, traffic, or engine releases change.
Database-native optimizers and vendor advisors are strong, but they expose one
vendor's search space and evidence. PlanRace creates a recurring open market for
executable query improvements.

The current digital commodity is a bounded structured index plan for an
already-correct query—not natural-language-to-SQL, not a generated answer, not
GPU rental, and not merely a benchmark rank. Miners remain free to use rules,
program search, learned systems, or specialized engine knowledge. The winner is
reusable and auditable by the buyer.

Bittensor fits the hypothesis that optimization discovery is open-ended while
bounded verification can be cheaper. Production-scale cost asymmetry remains
unproven. A validator can precommit hidden generated workloads,
authenticate every receiver-bound request, verify every miner-signed response,
and replay a bounded artifact. Exact canonical equality is the oracle: a wrong,
constant, malformed, late, or resource-abusive submission receives zero before
speed matters.

Only exact, compliant artifacts compete against the same-fixture baseline across
cold and warm latency, setup and storage, and multiple reuse horizons. A closed
multi-family schedule is aggregated conservatively. Identical artifacts share
one contribution, exact copies did not increase the tested strategy allocation, weights
are capped, and an all-fail round makes no update. The committed adversarial
simulation recorded zero accepted false claims and zero gaming weight across 512
replications. Behavior-equivalent replicas did improve availability, with a
worst simulated allocation gain of 13.57 percentage points. These bounded
results are not a universal Sybil-resistance proof.

The verified localnet run covered 30 epochs and six query families, using three
validator identities under one operator and ten heterogeneous miners. It
recorded 300 authenticated requests, 270 signed responses, and finalized
local-chain weight readback. Public testnet deployment and testnet weight
evidence remain pending. The final pitch must replace this interim boundary
with the actual testnet flow only after its signed evidence is verified.

The market wedge is recurring database-release regression, SaaS query-cost
reduction, and analytical-pipeline optimization using safe workload
descriptions. A centralized advisor still wins on privileged telemetry and
operational integration; PlanRace's value is solver diversity, transparent
competition, and validator-owned replayable evidence.

The current limits are material: generated SQLite workloads, one local operator,
no private customer adapter, no production-engine result, and testnet pending.
The roadmap is dedicated testnet proof, independent validators, DuckDB and
PostgreSQL tracks, privacy-preserving buyer adapters, and distributed benchmark
capacity. If validator cost approaches miner discovery cost or honest optimizers
cannot win across families, the roadmap for approved AST transformations is deferred.
PlanRace earns ecosystem value only if verification remains
objective, cheaper, and continuously useful.
