# Demo script

Target: 2:15 pending HackQuest's live duration limit. Shorten cuts rather than
speeding unreadable terminal footage. Never substitute simulation/localnet
footage for the required testnet segment.

1. **0:00–0:08 — Problem:** a known-correct query regresses as workload or engine
   changes; PlanRace sells an executable artifact, not an answer.
2. **0:08–0:18 — Challenge:** show engine/policy, known query, public training
   distribution, strict budget, and opaque task commitment; no seed/salt.
3. **0:18–0:30 — Signed request:** real testnet validator signs receiver-bound
   requests to heterogeneous registered miners.
4. **0:30–0:40 — Signed response:** show hotkey/signature/strategy digest and the
   sealed submission set.
5. **0:40–0:52 — Reveal:** after the deadline, reveal multiple hidden holdouts and
   verify the commitment.
6. **0:52–1:08 — Correctness:** exact miner passes; constant/wrong miner fails
   canonical equality before timing.
7. **1:08–1:20 — Sandbox:** timeout or over-budget attacker becomes unavailable
   while the validator continues.
8. **1:20–1:35 — Score:** show same-fixture baseline, cold/warm/setup/storage,
   reuse horizons, and conservative reward.
9. **1:35–1:45 — Aggregate:** show multi-validator ranking, duplicate split, and
   concentration cap.
10. **1:45–1:55 — Chain:** show real testnet commit/set, finalized extrinsic, and
    metagraph weight readback.
11. **1:55–2:05 — Evidence:** refresh Vercel, download raw manifest, run verification.
12. **2:05–2:15 — Limits:** generated workload, current engine, independent
    operators/private adapter roadmap.

Before export: verify voice/subtitle synchronization, terminal legibility at
1080p, no secrets or unnecessary IPs, and logged-out playback.
