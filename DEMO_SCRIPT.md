# Two-minute demo

1. **0:00–0:15 — Problem:** show one known-correct but slow SQL query.
2. **0:15–0:30 — Task:** validator commits an unrevealed test fixture and signs requests.
3. **0:30–0:50 — Competition:** indexed, baseline, and gaming miners respond.
4. **0:50–1:15 — Oracle:** reveal the fixture; exact result equality passes/fails before timing.
5. **1:15–1:30 — Score:** show median timing, setup amortization, and zero for wrong output.
6. **1:30–1:45 — Chain:** show normalized weights and metagraph/extrinsic readback.
7. **1:45–2:00 — Value:** a reusable optimization artifact, not another query answer.

Never substitute simulation/localnet footage for the pending testnet segment.
